你好，我是 zhongruimin

这张网页就放在我自己的 Git 仓库里。没有买服务器，没有买域名，也没有碰过一行后端代码 —— 它只是仓库里的一个 index.html 文件，GitHub 帮我把它变成了网址。

它是怎么跑到这里的

  • 本地建一个仓库，写一个 index.html
  • 推到 GitHub
  • 在仓库的 Settings → Pages 里把发布来源指向这个分支
  • 等一两分钟，网址就活了

以后改内容只要三行

  • git add .　把改动放进暂存区
  • git commit -m "说明"　拍一张快照
  • git push　推上去，网站自动更新
